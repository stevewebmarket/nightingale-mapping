# NMB3 Manifesto: Autonomous Nightingale Execution Loop

## Purpose

NMB3 exists to build a controlled autonomous execution loop for the Nightingale Mapping project.

The goal is not vague automation.

The goal is to move Nightingale toward funding-grade proof that it can capture, preserve, and reveal structure in sound through measurable bidirectional mapping.

## Current Strategic Path

1. Finish M3.1 — real invariance metric
2. Build M4 — killer demonstration
3. Build M5 — controlled optimization loop
4. Package evidence for funding

## Core Rule

The system may execute bounded tasks.

The system may not change project direction without Steve’s approval.

## Operating Principle

Every block must answer one question only.

Every run must produce evidence.

Every report must be traceable to:
- a command
- a file
- a result
- a decision

## Agent Roles

Steve:
- approves block transitions
- approves milestone transitions
- judges strategic direction

Manager Agent:
- creates one bounded block plan at a time
- prevents drift
- references current milestone

Execution Agent:
- runs approved commands
- creates logs and reports
- stops after the assigned block

Interpreter Agent:
- judges whether results are real
- flags fake progress
- recommends next block

## Current State

NMB3 is currently validating M3.1.

Block 001 has tested whether the invariance score moves under controlled mutations.

Next expected work:
- Block 002: isolate onset_delta
- Block 003: test baseline stability
- Block 004: test whether score corresponds to meaningful structural preservation

## Forbidden Behaviors

The system must not:
- invent broad new research directions
- optimize before metric validity is established
- rewrite the core pipeline without explicit assignment
- claim funding readiness without evidence
- move to M4 without Steve approval
- generate vague reports

## Success Definition

NMB3 succeeds when the system can:

1. Run bounded experiments online
2. Interpret results honestly
3. Generate the next bounded block
4. Preserve project direction
5. Move Nightingale closer to fundable evidence

## Final Operating Rule

Autonomy exists to multiply disciplined progress.

It does not replace judgment.
